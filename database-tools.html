Database tools

DBeaver Official site →

Verdict. The free all-rounder: one tool for almost any database, with a dense interface to match.

What it is. A free, open-source universal database client that connects to 100+ databases (PostgreSQL, MySQL, SQL Server, SQLite, Oracle and more) via JDBC, with a SQL editor, data editor, and ER diagrams.

Good.

  • Free Community edition covers most daily relational-database work
  • Widest database support of any free client, plus ER diagrams and data import/export
  • Cross-platform (Windows, macOS, Linux) with SSH tunneling and task scheduling
Bad.
  • Java-based, so it can feel heavy and slow to start
  • NoSQL, cloud databases, and advanced tools are locked behind paid Pro/Enterprise
  • Interface is dense and cluttered, with a learning curve for new users

Best for. Developers who juggle several different databases and want one capable free tool.

Price: Free Community edition (open source); paid Pro and Enterprise subscriptions · Official site · Docs · Download

TablePlus Official site →

Verdict. The fast, native-feeling client for daily querying — you pay once, not monthly.

What it is. A native, lightweight database client for macOS, Windows, Linux, and iOS, supporting relational databases (PostgreSQL, MySQL, SQL Server, SQLite) as well as MongoDB, Redis, and Cassandra.

Good.

  • Very fast to launch with a clean, modern interface and inline data editing
  • Perpetual license: buy once, keep using it forever, with one year of updates
  • Supports many databases including NoSQL, with safe staged edits before committing
Bad.
  • Free tier is limited to 2 open tabs, 2 windows, and 2 advanced filters at a time
  • Fewer admin and DBA features than DBeaver or DataGrip
  • Windows and Linux versions have historically lagged the Mac version

Best for. Developers who open a database client many times a day and value speed and a clean UI.

Price: Free tier (limited); paid perpetual licenses from $99 one-time · Official site · Docs · Pricing

DataGrip Official site →

Verdict. The smartest SQL editor you can buy — best-in-class autocomplete, at a subscription price.

What it is. JetBrains' cross-platform database IDE, with schema-aware SQL completion, code analysis, refactoring, visual explain plans, and support for 30+ database engines.

Good.

  • Best-in-class SQL autocomplete, introspection, and query analysis
  • Refactoring, version-control integration, and visual explain plans built in
  • Feels familiar if you already use a JetBrains IDE; included in the All Products Pack
Bad.
  • Paid subscription only for commercial use — no permanent free edition
  • JVM-based, so startup is slow and memory use is high
  • No visual query builder; it expects you to write SQL by hand

Best for. Professional developers and DBAs who write SQL all day and want the smartest editor.

Price: Paid subscription (individual and organization tiers, with continuity discounts); free for non-commercial use, students, and open-source contributors · Official site · Docs · Pricing

Beekeeper Studio Official site →

Verdict. The clean, friendly open-source client — great for everyday SQL, lighter on power features.

What it is. A modern, open-source SQL editor and database manager for PostgreSQL, MySQL, SQLite, SQL Server, Oracle, and more, with a free Community edition under GPLv3.

Good.

  • Clean, modern interface that is easy to pick up with no tutorial
  • Free Community edition is genuinely open source (GPLv3), with no telemetry or mandatory login
  • Same features on macOS, Windows, and Linux, and works offline by default
Bad.
  • Community edition covers the common SQL engines; NoSQL, AI, and backup/restore need paid tiers
  • Fewer advanced DBA and admin features than DBeaver or DataGrip
  • Desktop-only Electron app — no web or shared team instance

Best for. Developers who want a simple, pretty, open-source client for everyday PostgreSQL, MySQL, or SQLite work.

Price: Free Community edition (open source, GPLv3); paid Indie and Pro subscriptions · Official site · Docs · Pricing

pgAdmin Official site →

Verdict. The official PostgreSQL admin tool: free, deep, and battle-tested — but Postgres-only and dated.

What it is. The most popular open-source administration and development platform for PostgreSQL, with a SQL editor, schema browser, server monitoring dashboards, and backup/restore built on pg_dump and pg_restore.

Good.

  • Free and open source with the deepest PostgreSQL-specific support of any GUI
  • Backup/restore, server monitoring, and user/role management built in
  • Runs as a desktop app or a self-hosted web app for teams
Bad.
  • PostgreSQL only — useless if you also run MySQL, SQL Server, or MongoDB
  • Web-app UI wrapped in a desktop shell, so it feels slow and non-native
  • Interface is dated and can overwhelm beginners

Best for. Anyone administering PostgreSQL who wants the official, free, fully-featured tool.

Price: Free and open source (PostgreSQL License) · Official site · Docs · Download

DB Browser for SQLite Official site →

Verdict. The simplest way to open and edit a SQLite file — free, tiny, and single-purpose.

What it is. A free, open-source visual tool for creating, browsing, and editing SQLite database files, with a spreadsheet-style data view, SQL editor, and CSV/SQL import and export.

Good.

  • Completely free and open source, and very easy for beginners to learn
  • Lightweight and cross-platform, with a portable version that needs no install
  • Spreadsheet-style editing plus SQLCipher support for encrypted databases
Bad.
  • SQLite only — no support for server databases like PostgreSQL or MySQL
  • Can be slow with very large databases
  • Dated interface and no official support, only community help

Best for. Anyone working with local SQLite files, including app developers and learners.

Price: Free and open source (GPL) · Official site · Download · GitHub

Studio 3T Official site →

Verdict. The power tool for MongoDB professionals — unmatched for MongoDB, expensive and MongoDB-only.

What it is. A commercial MongoDB IDE for Windows, macOS, and Linux, with a Visual Query Builder, Aggregation Editor, IntelliShell with autocompletion, SQL Query, and schema exploration.

Good.

  • Most powerful MongoDB GUI: visual query builder, aggregation editor, and SQL-to-MongoDB translation
  • Schema Explorer, data import/export, and code generation for several languages
  • Free Community Edition for non-commercial use
Bad.
  • Expensive paid tiers, and MongoDB only — no relational databases
  • Feature-dense interface can overwhelm beginners
  • Requires creating a free Studio 3T account before use

Best for. Developers and teams who work with MongoDB daily and need its most advanced tooling.

Price: Free Community Edition (non-commercial use); Professional $499/user/year, Ultimate $699/user/year · Official site · Pricing · Knowledge base
