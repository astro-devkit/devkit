How this works

This page uses Transformers.js to run Gemma 3 270M IT (Google's small open model) directly in your browser, inside a Web Worker so the page never freezes. Inference uses WebGPU if your browser offers it, and falls back to WASM on your CPU.

  • Model: Gemma 3 270M IT, 4-bit quantized — and if it doesn't fit your device, the smaller SmolLM-135M loads instead, automatically
  • One-time download: ~293 MB, then cached by your browser for every future visit
  • Privacy: after the download, nothing you type leaves this page — there is no server to send it to
  • Cost: $0. Your device does the work, so there is no per-token bill
Honest expectations: a small 270M model that lives in your RAM — fun and instant, not GPT-class. It will write plausible text, answer simple questions, and cheerfully make things up. For real API models and what they cost, see the LLM cost calculator.
